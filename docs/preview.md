# 酒店预订系统界面原型

这是实验二的可点击界面设计，使用 Fluent UI React v9 官方组件和浅色主题；数据与操作均为浏览器中的演示。本轮没有接入 Go 服务或真实账户。

## 查看与操作

启动原型后在本机打开 <http://localhost:5173/>。

- 顾客：探索酒店 → 选择房型 → 填写预订；使用“顾客示例账户”进入订单管理。
- 工作人员、管理员：右上角账户菜单切换对应的“原型演示”视图。
- 价格变化、无房、结果查回：页脚“原型场景”可切换下一次预订的反馈。
- 恢复示例：在“原型场景”中重置演示数据；会清除当前浏览器中的原型操作。

## 本地开发与检查

```bash
npm ci
npm run dev:prototype
npm run check
npm run build -- --mode prototype
npm run browser:install
npm run test:ui
npm run screenshots
```

浏览器检查命令使用项目本地的 `.local/browsers/`，截图命令需要预览服务正在运行。当前工具配置用于本 Linux 工作区，客户端目标平台仍按项目设计约定覆盖 Windows 11、macOS、iPadOS、Android。

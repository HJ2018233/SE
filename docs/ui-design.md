# 酒店预订系统 UI 设计约定

状态：2026-11-13，用户以“你做吧”确认推荐方向后，已制作可点击原型与课程截图；业务实现留待后续实验。

## 已确认基线

- 延续 `Lab1/requirements.md` 的 22 条需求与既有 UML。
- React + TypeScript 界面供 Tauri 客户端复用；本轮交付设计与可点击原型。
- 顾客、酒店工作人员、平台管理员均覆盖桌面、平板、手机尺寸。
- 使用 Fluent，用户本轮明确允许按官方推荐方式引入代码。
- 顾客端不沿用概念图 B 的侧栏；照片空间层次是审美参考，不是每页固定装饰。

## 官方接入

采用 Fluent UI React v9：`@fluentui/react-components`、`@fluentui/react-icons` 与根部 `FluentProvider`。使用官方 `webLightTheme`，不先行发明另一套控件外观。

2026-11-13 读取官方 npm registry 的稳定版本与兼容范围：

| 包 | 固定版本 |
|---|---|
| @fluentui/react-components | 9.75.2 |
| @fluentui/react-icons | 2.0.345 |
| react / react-dom | 19.3.1 |
| @types/react / @types/react-dom | 19.3.0 |
| typescript | 7.0.2 |

Fluent 9.75.2 声明 React 与 React 类型兼容范围为 `>=16.14.0 <20.0.0`。安装结果与检查结果另记，不以版本查询代替安装成功。

已完成根目录安装与 `package-lock.json` 锁定。`src/design-system.tsx` 提供共用主题入口，所有业务页面实际使用官方组件、图标与语义令牌。运行与检查入口见 `docs/preview.md`。

## 规范落实

- 按钮、字段、下拉选择、页签、弹窗、抽屉、消息条及图标采用官方组件；保留其焦点与键盘行为。
- 界面颜色、字号、行高、间距、圆角、阴影、动画采用 Fluent 语义令牌；版面使用官方间距梯度。
- 正文采用系统字体与 Fluent 字体层级，照片与构图承担酒店场景的个性。
- 移动端交互区以 48 × 48 为目标，满足 Android 48 × 48 与 iOS/Web 44 × 44 的最低建议；主要动作有可直接点击的入口。
- 从 320 像素起检查重排；手机上完成查询、选房、报价确认、下单、查回和取消时不依赖页面横向滚动。
- 焦点可见，弹窗关闭后焦点返回触发处；状态同时使用文字，不仅用颜色；照片提供替代文字。
- 创建前展示逐晚价与整段总额；价格变化须重新同意；改订成功前保持原单有效。

## 已确认并制作的页面与交互方案

推荐方向暂称“旅宿手册”，仅用于讨论设计，不替换产品名称。

| 角色 | 页面组织 | 关键交互建议 |
|---|---|---|
| 顾客 | 顶部导航，错落图文酒店列表，住宿条件可展开；手机以浏览为中心 | 明确入口比较酒店、查看房型；连续住宿日展示逐晚报价；改订并列展示原单和新方案 |
| 酒店工作人员 | 房量日历与订单处理两个核心视图 | 日期与房型关联编辑；待确认倒计时与状态对应操作；异常逐单处置 |
| 平台管理员 | 酒店、账户权限与异常事件 | 从事件进入关联订单和脱敏审计；处理时间线呈现联系与处置进度 |

用户已确认该方向。顾客页面采用照片与报价信息的错位叠合，手机选房页保留固定报价与预订入口；酒店日历在手机上改为按日查看，管理表格重排为带标签的逐条明细。

## 功能覆盖清单

| 模块 | 需要覆盖的界面状态 | 需求 |
|---|---|---|
| 账户与权限 | 登录、顾客注册、个人入口、工作人员创建和酒店绑定、账户停用 | REQ-001、019 |
| 酒店与房型 | 酒店资料、房型维护、酒店启停 | REQ-002 |
| 房量价格日历 | 每日总量、占用、剩余、可订、价格、停售；批量编辑与冲突反馈 | REQ-003 |
| 搜索与选房 | 首次查询、结果筛选、空结果、酒店详情、房型选择、逐晚报价 | REQ-004、005、022 |
| 预订 | 联系信息与校验、提交中、报价变化、成功待确认、结果查回 | REQ-005、006、007、018、020、021 |
| 我的订单 | 筛选、七种状态详情、确认期限、业务历史、异常进度、改订、取消 | REQ-008、009、010、013、017 |
| 酒店履约 | 接受、拒绝及原因、超时、入住时间窗口、退房与提前退房 | REQ-008、011 |
| 异常事件 | 影响范围、先停售、关联订单、联系中、逐单处置、事件完成条件 | REQ-012 |
| 统计导出 | 逐晚占用与有效间夜约定金额、关联订单明细、同一时点 CSV | REQ-014 |
| 审计与联系方式 | 脱敏日志、用途登记、关联事件、完整号码查看、到期禁读 | REQ-015、016、019 |

不增加支付、退款、评价、地图、自动换店等现有范围外业务。页面中的演示内容需明确为原型数据；角色演示切换不代表公开注册能够获取管理权限。
